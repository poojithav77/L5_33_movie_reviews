# Lab 5: Static Code Analysis
## Movie Reviews Project

### 1. Objective

The objective of this lab is to perform static code analysis on a Python program using Pylint, Bandit, and Flake8. These tools help identify code quality problems, potential security vulnerabilities, and formatting errors. The identified issues were corrected, and the tools were run again to verify the improvements.

### 2. Tools Used

1. **Pylint:** Checks Python code quality, naming conventions, documentation, and programming practices.
2. **Bandit:** Identifies potential security issues in Python code.
3. **Flake8:** Checks Python code for style and formatting violations.

### 4. Reflection Questions and Answers

**Q1. What is static code analysis?**

Static code analysis is the process of examining source code without running the program. It helps identify potential bugs, security problems, coding standard violations, and formatting issues.

**Q2. What is the purpose of Pylint?**

Pylint checks Python code quality. It identifies issues such as naming convention violations, missing documentation, and other programming practices that can make code harder to maintain. In this lab, the final Pylint score was 10.00/10.

**Q3. What is the purpose of Bandit?**

Bandit checks Python source code for common potential security vulnerabilities. In this lab, security-related improvements included removing the hardcoded password, replacing MD5 with SHA-256, and using `secrets.choice()` for selecting the featured movie. The final Bandit report identified no issues.

**Q4. What is the purpose of Flake8?**

Flake8 checks Python code for style and formatting problems, including whitespace, indentation, and line-length violations. After the corrections, the final Flake8 report contained no errors.

**Q5. What improvements were made to the program?**

The program was improved by replacing the hardcoded password with an environment variable, changing the listening host to `127.0.0.1`, replacing MD5 with SHA-256, using `secrets.choice()`, validating whether a movie exists before accepting a rating, following snake_case naming conventions, removing unnecessary global state, adding docstrings, and improving formatting.

**Q6. What did you learn from this lab?**

I learned that static analysis tools help improve code quality, readability, and security before a program is executed or deployed. I also learned that different tools focus on different areas: Pylint focuses on code quality, Bandit focuses on potential security issues, and Flake8 focuses on coding style and formatting. Using all three provides a more complete review of a Python program.
